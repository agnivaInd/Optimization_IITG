# Optimization_IITG
Codes for single variable, multivariable and constrained optimization

Single variable optimization problems are handled using Bounding Phase method, followed by Bisection method.

Multivariable optimization problems are handled using the Conjugate Gradient method, in which unidirectional search is performed by the single variable optimization process as mentioned above.

Constrained optimization problems are handled using Bracket Operator Penalty method added to the multivariable framework.

Each optimization process is tested on multiple functions.

All codes were developed in a team of 2 students.
